Para qué

Cuando el agua está honda

Estructura reforzada y mayor carrera para elevar agua de napas profundas y mantener el tanque lleno donde el Huracán se queda corto.

Con Famacon Control, cada Hércules queda monitoreado igual: si el tanque baja y el equipo está parado, te avisa.
